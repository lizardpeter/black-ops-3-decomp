# Builds

Inventory of every BO3 build available, with provenance. target.toml holds the machine-readable part (R2 key,
sha256, kind); this page holds the reasoning: where each file came from, its signature and whether it verifies,
timestamps, debug-directory PDB path and GUID, Rich header (compiler), protection, and why it was chosen as
reference, target or helper.

The game files are being uploaded to R2. Nothing is inventoried yet.
