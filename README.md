# black-ops-3-decomp

Decompilation of **Call of Duty: Black Ops III (T7)**, PC x64: a faithful reconstruction verified function by
function against the original binaries, and (later) an enhanced build with documented fixes and improvements.

Method and tools come from [ghosts-decomp](https://github.com/lizardpeter/ghosts-decomp) and
[black-ops-1-decomp](https://github.com/lizardpeter/black-ops-1-decomp). Start with [AGENTS.md](AGENTS.md);
progress is in [STATUS.md](STATUS.md).

The original game files are not in this repo. You need your own copy.
